Before you deploy

  1. Insert the [from-trunk] lines under the existing DID checks and jumps.
  2. Add both generated contexts to extensions.conf.
  3. Add the queue block to queues.conf (no static members).
  4. Run the CLI commands to reload and attach every agent.
  5. Upload any audio files to /var/lib/asterisk/sounds/en.

Production connection rules

  • Caller ID and the TATA header are emitted before every sticky/IVR GotoIf.
  • Inbound sticky uses ODBC_INBARERA; outbound sticky uses ODBC_TDUCESTICKYAPILASTCALL.
  • Every agent, IVR and sticky dial is 11 digits: 0<10-digit>.
  • Sticky matches use a 30 second ring; unmatched calls fall back to the queue.
